# CurriculumVitae

This repository contains LaTex code for my personal Curriculum Vitae.

Inspired by [Jake Gutierrez's Resume](https://www.overleaf.com/latex/templates/jakes-resume/syzfjbzwjncs)

The CV is available in three languages. They share a common preamble (`cv/cv_preamble.tex`, which loads `babel` with `italian,ngerman,english`) and are compiled with `pdflatex`:

- English: `cv/zuppichini_curriculum.tex` — [View my CV](cv/zuppichini_curriculum.pdf)
- Italian: `cv/zuppichini_curriculum_it.tex`
- German: `cv/zuppichini_curriculum_de.tex`
